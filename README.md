# Gully Dash: India Rush

A portrait-mode 2D arcade endless runner for Android, built with Godot 4 and GDScript.

## Prototype features

- Three-lane road and left/right lane switching
- Keyboard controls for desktop testing and screen-side taps for mobile
- Auto-rickshaw player represented with original procedural placeholder graphics
- Traffic obstacles, collisions, coins, score, game over and restart
- No login, backend or network connection required

## Run

1. Install Godot 4 from https://godotengine.org/download/
2. Clone this repository.
3. In Godot, import `project.godot`.
4. Press F6 to run the main scene, or F5 to run the project.

## Controls

- Tap/click left side: move one lane left
- Tap/click right side: move one lane right
- Keyboard: Left/Right arrow or A/D
- Start/restart: Space or Enter
